# Suggested Git history

Use small commits with names that describe the engineering change. Avoid generic messages such as `Add files via upload`.

Suggested sequence for the clean Nationals repository:

1. `Initial final repository structure`
2. `Add final CAD and STL exports`
3. `Add final electrical schematic`
4. `Update final 4WD drivetrain`
5. `Add two-camera architecture`
6. `Fix steering calibration values`
7. `Update obstacle avoidance`
8. `Fix parking state machine`
9. `Add IMU safety handling`
10. `Add final testing results`
11. `Add measured power values`
12. `Add beginner build guides`
13. `Update README with final robot views`
14. `v1.0 – Nationals Configuration`

Do not claim a feature in a commit message unless the corresponding code/CAD/testing evidence is in the repository.
