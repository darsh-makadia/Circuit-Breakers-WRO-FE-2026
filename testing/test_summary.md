# Nationals Testing Summary

## Open Challenge

Six complete anticlockwise runs were recorded:

| Run | Time |
|---:|---:|
| 1 | 32 s |
| 2 | 30 s |
| 3 | 28 s |
| 4 | 28 s |
| 5 | 28 s |
| 6 | 28 s |

**Best recorded time: 28 s**

The later runs repeating 28 s are useful evidence of repeatability under the tested conditions. The dataset is small, so it is not presented as a statistical performance claim.

## Obstacle Challenge

Six autonomous obstacle-navigation runs were recorded:

| Run | Time |
|---:|---:|
| 1 | 2:10 |
| 2 | 2:09 |
| 3 | 2:11 |
| 4 | 2:20 |
| 5 | 2:15 |
| 6 | 2:13 |

**Best recorded navigation time: 1:09**

These times cover obstacle navigation **up to the parking approach**. The final parking manoeuvre was tested separately and is not included in these timed runs because it is not yet reliable enough to claim as a completed full sequence.

## Processing observations

The updated engineering document records observed samples of approximately:

- Open Challenge: **14.1 FPS mean loop rate**
- Obstacle Challenge: **11.25 FPS mean loop rate**

These are observed samples, not guaranteed fixed operating rates.
